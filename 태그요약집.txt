1. 모든 태그는 <>로 감싼다.
2. 시작태그와 종료태그가 있다. ex.<h2></h1>
3. 시작태그와 종료태그가 함께 있는 것도 있다. ex. <br />
4. 태그 종류
- 제목 태그 : h1 ~ h6(h가 붙으면 다 블럭요소)
- 웹페이지의 제목 : title
- 단락구분 : p
- 한줄 띄우기 : br
- 이미지 : img
- 링크 : a
- 강조 : strong, 기울임: em
- 구분선 : hr
- 목록 만들기 : 번호목록(ol - ordered list의 준말), 불릿(번호 없는 목록)(ul, unordered list의 준말)
- 목록 안의 리스트 : li(list 준말)

******** div와 span 태그
-div : 구역을 나누는 태그(의미없는 영역 잡는 데 사용함.)
    -대표적인 블럭요소(입력된 값의 줄을 모두 포함함)
-span : 의미 없는 작은 상자 - 자기 크기만큼만 잡힌다.
    -대표적인 인라인요소(입력값만 포함함)

================
- 대표적인 블럭요소 : div, p, h1~h6, ul, li, form
- 대표적인 인라인요소 : span, a, strong, em, img

================
- 시멘틱 태그 : div 태그이지만 의미만 갖는 태그
    -종류 : header, footer, main, article, nva 정도

-emmet :  HTML 구조를 빠르게 만듦.
! : HTML 뼈대 만들기
class : html의 여러 개를 같은 이름으로 사용 가능(중복 가능) -> <div class="a" /> -> .a
   -> ex. 남자는 손들기(개인 이름은 다 다르지만 남자이면 손들기)
. : class를 뜻함.
# : id를 뜻함.(class와 같지만 중복 불가)<div id="b" -> #b
> : 자식(~으로 이동)
+ : 형제
* : 반복
{} : 안에 들어갈 글자
$ : 번호
^ : 옆집
[] : 속성
